# Kana (Hiragana and Katakana)

The **"Kana"** section serves as a quick reference for Japanese syllabaries.

## Switching Modes

A **toggle** is located at the top of the screen:

*   **Hiragana (あ)** – the primary syllabary.
*   **Katakana (ア)** – the syllabary used for borrowed words.

Selecting a mode changes the displayed character table.

## Character Cards

Each character is displayed as a **card**, which contains:

1.  **The Character Itself** – in a large, clear font for visibility.
2.  **Reading in Romaji** – in a smaller font at the bottom of the card.
