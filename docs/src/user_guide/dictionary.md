# Dictionary and Search

The main screen and the **"All Kanji"** screen provide full access to the kanji database.

## Search

The search bar allows you to filter and find kanji based on several criteria:

*   **Character (Kanji)** – search by the symbol itself.
*   **Readings (On'yomi / Kun'yomi)** – both kana and romaji are supported.
*   **Meaning (translation)** – search through localized word meanings.

> ⚙ In the settings, you can enable the `Focus on search` option. This will automatically place the cursor in the search field when the application starts.

## Filter by JLPT

On the kanji list screen, a **dropdown menu** is available to filter by JLPT (Japanese-Language Proficiency Test) levels:

*   **N5 (Beginner)** → **N1 (Advanced)**
*   **All** – show all available kanji

## Detailed Kanji View

Clicking on a kanji card opens the detailed view:

1.  **Animation**

    *   An animated stroke order diagram of the character is displayed on the left.
    *   Clicking on the animation area replays it.
    *   The animation speed can be configured in the **Settings** menu.

2.  **Kanji Information**

    *   Meaning
    *   JLPT level, school grade (Grade), stroke count, usage frequency
    *   **Readings**: On'yomi and Kun'yomi with romaji transcription

3.  **Usage Examples**

    *   A list of words or phrases that include this kanji
    *   If the localization file contains translations for the examples, they are displayed in italics below the original.
