# Flashcards and Decks

The **"Cards"** mode allows you to test your knowledge using **flashcards**.

## Setting Up a Session

Before starting a practice session, you can choose the **card source**:

1.  **By JLPT Levels**

    *   Select the desired level (N5–N1).
    *   Use the **Card count** slider to set a limit on the number of cards, preventing overload (e.g., 10–20 random cards).

2.  **Custom Decks**

    *   Select a previously created deck from the **My Decks** list.
    *   Custom decks are useful for studying specific sets of kanji.

## Active Session

During the practice session:

1.  A kanji character is displayed.
2.  Think about its meaning and reading.
3.  Click on the card (or the **Click to flip** button) to flip it over.
4.  The back shows: meaning, on'yomi, and kun'yomi.
5.  Click **Next** to proceed to the next character.

> Upon completing a deck, a screen with the session results is displayed.

## Deck Manager

Allows you to create and edit your own study sets:

*   **Creating a Deck**
    Enter a deck name, find the desired kanji using the search function, and add them with the **Add** button.

*   **Editing**
    Modify the deck's title, add or remove cards.

*   **Saving**
    Click **Save Deck** (or **Update**) to save your changes.
