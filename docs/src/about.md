# About the Project

**Kanji Master** was initially created by the developer as a tool for personal kanji study. Over time, the project was opened to the public so others could use it freely.

The project's goal is to provide a **fast, lightweight, and visually appealing tool** for learning Japanese and working with kanji on desktop systems. It is aimed at users who need **free and customizable solutions**, as opposed to many commercial or closed-source applications.
